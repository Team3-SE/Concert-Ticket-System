    note for Admin "Ban/unban is handled by AppUser.ban() / activate()<br>Coordination steps (permission check, AuditLog recording) are handled by the Controller"

    Organizer "1" --> "0..*" NamingTemplate : owns
    NamingTemplate "0..1" --> "0..*" ZoneSeatPattern : is template for
    Concert "1" --> "1..*" Zone : consists of
    Zone "1" *-- "0..*" ZoneSeatPattern : defines pattern (cascade delete with Zone)
    ZoneSeatPattern "0..1" --> "0..*" Seat : generates seats
    Zone "1" *-- "0..*" Seat : contains seats (cascade delete with Zone)

    note for Zone "A Zone can be deleted only when no BookingSeat / SeatLockLog / Ticket references it<br>Otherwise the DB rejects the deletion (RESTRICT) - checked and deleted via SeatMapController.deleteZone<br>STANDING zone: totalRows, seatsPerRow can be NULL (capacity can be NULL in the DB)<br>seatStartNumber is NOT NULL (default 1)"
    note for ZoneSeatPattern "Deleting a NamingTemplate keeps the Pattern<br>(relationship to the template is 0..1)"
    note for Seat "Deleting a ZoneSeatPattern keeps the Seat<br>(relationship to the Pattern is 0..1)"
